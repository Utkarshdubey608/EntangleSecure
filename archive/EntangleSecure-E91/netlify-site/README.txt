EntangleSecure Netlify static demo

Deploy this folder by dragging the netlify-site folder into Netlify's manual deploy drop zone, or upload EntangleSecure-Netlify.zip.

The site is static HTML, CSS, and JavaScript. No build command or server configuration is required.

Important: Netlify cannot run the original Python/Streamlit application. This bundle is an educational static showcase with a simplified browser-side E91 correlation model. It is not a replacement for the full simulation or a security certification. The original app remains available in the parent project; run it with:

  streamlit run app.py
