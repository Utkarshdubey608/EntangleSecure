QuantumVote

Ballots are encrypted with ML-KEM-768 (FIPS 203) and AES-256-GCM. Receipts and results are signed with ML-DSA-65 (FIPS 204). The public bulletin board is a SHA3-256 hash chain.

Academic demonstration. Ballot cryptography runs on the server for this demo; in a deployed system it would run on the voter's own device.
